\chapter{系统设计与实现}

本章详细阐述基于Actor-Critic架构的视频前处理优化系统的整体设计与实现。在进入具体设计之前，有必要说明本方案的选型过程。在项目早期，笔者首先尝试了基于监督学习的率感知预处理方案RPP\cite{ref17-ma2023rateperception}。RPP通过自适应DCT损失函数智能去除高频冗余，在原生分辨率、软件编码器(x265)的测试中取得了显著的BD-Rate收益。然而，将其部署到NVENC硬件编码器的2$\times$下采样流水线中时，效果却不如纯硬件基线方案。经过深入的频谱分析和反复调试，笔者定位到两个根本性问题：其一，RPP的DCT优化策略是基于输入分辨率设计的，在4K尺度下被判定为可以牺牲的中频纹理，恰恰是下采样后1080p画面中仅存的清晰度来源，导致处理后画面严重发糊；其二，RPP输出的低方差平滑信号触发了NVENC码率控制算法的误判——硬件编码器将其识别为平坦区域并激进地提高QP，最终造成块效应和色带，画质严重过平滑并伴随明显块状伪影。这一失败经验说明，基于监督学习的前处理方案本质上无法感知编码器的行为，必须引入一种能够将编码器纳入优化回路的训练范式。因此本文最终选择强化学习框架：将不可导的NVENC视为黑盒环境，通过编码器感知的方式使前处理模型能够针对硬件编码器的特性（如量化步长、块划分模式）\cite{ref6-li2021deep}进行预补偿，有效缓解低码率场景下的质量崩塌。

\section{状态空间与动作空间设计}

\subsection{状态空间构建}

定义$t$时刻的状态空间$s_t$为待编码的原始视频帧序列。鉴于NVENC硬件编码器及主流视频标准广泛采用YCbCr 4:2:0格式，系统首先通过双线性插值(Bilinear Interpolation)将下采样的色度分量(Cb, Cr)上采样至与亮度分量(Y)相同的空间分辨率。最终构建的输入状态张量形状为$(B \times T, 3, H, W)$，其中$T$为时序长度，旨在利用视频帧间的时域相关性辅助决策。

\subsection{动作空间定义}

为了克服直接生成像素可能导致的训练震荡与收敛困难问题，系统采用\textbf{残差学习}(Residual Learning)策略。Agent的输出并非直接的像素值，而是针对原始帧的残差修正量。定义$t$时刻的状态为原始视频帧$s_t$，网络输出为残差图$f_{\text{Actor}}(s_t)$，则最终生成的动作$a_t$表示为：

% ============================================================
% 【示例：如何插入公式】
% ============================================================
\begin{equation}
  a_t = \text{clamp}(s_t + f_{\text{Actor}}(s_t), 0, 1)
  \label{eq:action}
\end{equation}

其中，$\text{clamp}(\cdot, 0, 1)$ 操作用于将叠加后的像素值强制约束在合法区间 $[0, 1]$ 内，确保输入硬件编码器的视频帧数据有效。


\section{Random Crop训练策略}

在早期的系统设计中，训练时采用2$\times$下采样将1080p视频缩小为540p进行编码。在该方案下，模型的PSNR指标有所提升，但主观观看时却发现画面边缘明显模糊、纹理细节丢失严重。对训练数据进行频谱分析表明问题主要来自：下采样操作直接截断了Nyquist频率以上的高频分量，导致模型从一开始就没有真实的高频纹理，自然也无法学会保护这些细节。这一失败经验促使笔者重新审视训练数据的构建方式。

为此，本文提出了基于随机裁剪(Random Crop)的训练策略：从1080p原始帧中随机裁剪$540 \times 960$的区域作为训练样本。该策略在保持与下采样方案相同的编码分辨率和计算开销的前提下，完整保留了原始视频的高频信息。核心实现如代码~\ref{lst:random-crop}所示。

\begin{lstlisting}[language=Python, caption={YUV420 Random Crop}, label={lst:random-crop}]
def random_crop_yuv420_clip(y, cb, cr, crop_h, crop_w):
    # Random crop a fixed-size region from YUV420 clip
    # y:  (T,1,H,W)      Luma channel
    # cb: (T,1,H/2,W/2)  Chroma Cb channel
    # cr: (T,1,H/2,W/2)  Chroma Cr channel
    # crop_h, crop_w:    Crop size (must be even)
    T, _, H, W = y.shape
    # Random start position (aligned to 2 for YUV420)
    top = random.randint(0, H - crop_h) // 2 * 2
    left = random.randint(0, W - crop_w) // 2 * 2
    # Crop Y channel
    y_crop = y[:, :, top:top+crop_h, left:left+crop_w]
    # Crop Cb/Cr channels (half resolution)
    top_c, left_c = top // 2, left // 2
    crop_h_c, crop_w_c = crop_h // 2, crop_w // 2
    cb_crop = cb[:, :, top_c:top_c+crop_h_c,
                      left_c:left_c+crop_w_c]
    cr_crop = cr[:, :, top_c:top_c+crop_h_c,
                      left_c:left_c+crop_w_c]
    return y_crop, cb_crop, cr_crop
\end{lstlisting}

需要特别注意的是，YUV 4:2:0格式要求裁剪坐标必须是2的倍数，以保证亮度与色度通道的空间对齐。在环境的\texttt{reset()}方法中，每个episode都会随机选择新的裁剪位置，从而实现数据增强效果。


\section{复合奖励函数设计}

针对低码率场景下主观画质与传输带宽的博弈难题，设计了基于参考率失真(Reference Rate-Distortion)特性的复合奖励函数。该函数旨在引导模型在相对于基准编码器(Baseline)的相对增益中寻找平衡点，其数学形式定义如下：

\begin{equation}
  R_{total} = \alpha \cdot \frac{V_{cur} - V_{ref}}{|V_{ref}|} + \beta \cdot \frac{R_{ref} - R_{cur}}{R_{ref}}
  \label{eq:reward}
\end{equation}

式中，$V_{cur}$ 和 $R_{cur}$ 分别为当前动作经NVENC编码后解码获得的感知质量分数（采用LPIPS取负，值越大表示质量越好）和实际码率（kbps）；$V_{ref}$ 和 $R_{ref}$ 为基准编码器在同等量化参数(QP)下的参考值。$\alpha = 200$ 与 $\beta = 100$ 为超参数，分别用于调控感知质量增益与码率节省的权重。

为了实现跨码率点的泛化能力，系统在每个训练step中对同一段视频分别在QP $\in \{37, 40, 42, 45, 47\}$ 五个量化参数下进行编码，取所有QP点的平均奖励作为最终奖励信号：

\begin{equation}
  R_{avg} = \frac{1}{|\mathcal{Q}|} \sum_{q \in \mathcal{Q}} R_{total}(q)
  \label{eq:reward-avg}
\end{equation}


\section{网络损失函数建模}

为了确保Actor-Critic架构的稳定收敛，针对Critic和Actor网络分别设计了差异化的优化目标。

\subsection{Critic网络损失}

Critic网络(ValueNet)旨在准确评估当前策略的价值，其训练目标是最小化预测$Q$值与真实奖励$R_{total}$之间的均方误差(MSE)：

\begin{equation}
  \mathcal{L}_{\text{Critic}} = \text{MSE}(V(s_t, a_t), R_{total})
  \label{eq:critic-loss}
\end{equation}

\subsection{Actor网络损失}

Actor网络(RAPNet)的损失函数采用频域感知的复合损失策略，由策略梯度损失和多个空间频率感知正则项构成：

\begin{equation}
  \mathcal{L}_{\text{Actor}} = \underbrace{-Q_\phi(s, \pi_\theta(s))}_{\text{策略梯度}} + w_{\text{mse}} \cdot \mathcal{L}_{\text{mse}} + w_{\text{hf}} \cdot \mathcal{L}_{\text{hf}} + w_{\text{TV}} \cdot \mathcal{L}_{\text{TV}}
  \label{eq:actor-loss-full}
\end{equation}

各项的具体定义如下：

\textbf{（1）策略梯度损失}$\mathcal{L}_{\text{policy}}$：旨在最大化Critic对当前动作的评分，引导网络生成高回报的增强帧。通过最大化该估值（即在损失函数中取负号进行最小化），迫使Actor网络朝着Critic认为能够获得更高奖励的方向调整输出动作：
\begin{equation}
  \mathcal{L}_{\text{policy}} = -\mathbb{E}[Q_\phi(s_t, f_{\text{Actor}}(s_t))]
  \label{eq:policy-loss}
\end{equation}

\textbf{（2）加权MSE损失}$\mathcal{L}_{\text{mse}}$：用于约束生成帧与原始帧在低频内容上的结构一致性，防止色彩偏移。采用加权均方误差形式（亮度通道权重更高）：
\begin{equation}
  \mathcal{L}_{\text{mse}} = 6 \cdot \text{MSE}(Y, \hat{Y}) + 1 \cdot \text{MSE}(C_b, \hat{C}_b) + 1 \cdot \text{MSE}(C_r, \hat{C}_r)
  \label{eq:mse-loss}
\end{equation}

\textbf{（3）非边缘高频抑制损失}$\mathcal{L}_{\text{hf}}$：这是本文损失设计的核心创新。利用Sobel算子对原始帧进行边缘检测，生成软边缘掩模$E \in [0, 1]$（边缘处值高、平坦处值低），然后仅在\textbf{非边缘区域}惩罚Actor引入的高频修改：
\begin{equation}
  \mathcal{L}_{\text{hf}} = \frac{1}{N} \sum \left| \text{HP}(\delta) \right| \cdot (1 - E)
  \label{eq:hf-loss}
\end{equation}
其中，$\delta = a_t - s_t$为Actor输出的修改量，$\text{HP}(\cdot) = \delta - \text{LP}(\delta)$为高通滤波（减去$5 \times 5$均值模糊的低频分量），$E$为Sobel边缘掩模（通过$E = 1 - e^{-k \cdot \hat{e}}$生成软掩模，$k = 10$控制掩模锐度）。该设计允许模型在边缘区域自由修改以增强锐度，但在平坦区域抑制高频噪声以避免编码器浪费码率。

\textbf{（4）全变分平滑损失}$\mathcal{L}_{\text{TV}}$：为了抑制由卷积操作引起的棋盘格伪影及高频噪声，引入各向异性全变分损失(Anisotropic Total Variation Loss)。该损失通过最小化相邻像素间的差异来提升图像的空间平滑度：
\begin{equation}
  \mathcal{L}_{\text{TV}} = \frac{1}{N} \sum_{b,c,h,w} \left[ (\hat{x}_{b,c,h+1,w} - \hat{x}_{b,c,h,w})^2 + (\hat{x}_{b,c,h,w+1} - \hat{x}_{b,c,h,w})^2 \right]
  \label{eq:tv-loss}
\end{equation}

其中，$N = B \times C \times H \times W$ 为归一化因子，确保损失数值不随分辨率变化而波动；$\hat{x}$ 代表Actor输出的增强帧。训练中各损失权重设置为$w_{\text{mse}} = 5$、$w_{\text{hf}} = 10$、$w_{\text{TV}} = 0.1$。

\subsection{Actor网络(RAPNet)结构}

RAPNet采用“PixelUnshuffle → 残差学习 → PixelShuffle”的编码-解码结构：

\begin{enumerate}
  \item \textbf{输入层}：PixelUnshuffle将$(1, H, W)$重排为$(4, H/2, W/2)$，随后通过$3 \times 3$卷积 + LeakyReLU提取浅层特征；
  \item \textbf{主干层}：5个ResBlock进行残差学习，每个ResBlock包含$3 \times 3$卷积 + LeakyReLU + $3 \times 3$卷积 + 残差连接；
  \item \textbf{输出层}：$3 \times 3$卷积 + LeakyReLU + PixelShuffle恢复空间分辨率，输出残差叠加后的增强帧。
\end{enumerate}

对Y、Cb、Cr三个通道分别设置独立的处理支路，最终输出与输入相同尺寸的YUV420帧。该架构通过PixelShuffle/Unshuffle实现的轻量级上下采样，有效控制了参数量和计算开销。

\subsection{Critic网络(ValueNet)结构}

ValueNet采用双分支特征融合架构：

\begin{enumerate}
  \item \textbf{输入分支}与\textbf{输出分支}分别通过Conv + LeakyReLU + Conv提取特征；
  \item \textbf{特征融合}：Concat两个分支特征；
  \item \textbf{回归预测}：$3 \times 3$卷积 $\to$ 全局平均池化(AvgPool) $\to$ MLP(Linear $\to$ ReLU $\to$ Linear)输出标量$Q$值。
\end{enumerate}

该双分支架构使Critic能够同时感知原始输入和Actor输出的差异，从而更准确地评估动作价值。

\section{训练算法}

本文的训练算法基于Actor-Critic框架，采用多GPU并行策略：Actor(RAPNet)部署在GPU 0上，Critic(ValueNet)部署在GPU 1上，通过参数同步机制保持一致性。训练过程中的关键设计包括：

\begin{itemize}
  \item \textbf{多GPU协同}：Actor和Critic分别部署在不同GPU上，Critic更新完毕后将参数同步到GPU 0上的副本$Q_{\phi'}$（仅用于前向推理，不参与反向传播），避免跨GPU的自动求导断链问题；
  \item \textbf{多QP联合训练}：每个step对5个QP点编码并取平均奖励，使网络适应不同码率场景而非过拟合到单一QP；
  \item \textbf{梯度裁剪}：Actor梯度范数裁剪至1.0，Critic梯度范数裁剪至10.0，防止训练早期因奖励不稳定导致梯度爆炸。
\end{itemize}

优化器采用Adam，Actor学习率$1 \times 10^{-5}$，Critic学习率$2 \times 10^{-5}$，每1000次迭代衰减为原来的$1/3$。完整的训练流程如算法~\ref{alg:training}所示。

\begin{algorithm}[htbp]
\caption{基于Actor-Critic的编码器感知前处理训练算法}
\label{alg:training}
\KwIn{视频数据集 $\mathcal{D}$，Baseline RD表，QP集合 $\mathcal{Q} = \{37, 40, 42, 45, 47\}$}
\KwOut{训练好的Actor网络参数 $\theta^*$}
初始化 Actor $\pi_\theta$ (GPU 0), Critic $Q_\phi$ (GPU 1), Critic副本 $Q_{\phi'}$ (GPU 0)\;
构建 Baseline RD 参考表: $\{R_{ref}(v, q), V_{ref}(v, q)\}_{v \in \mathcal{D}, q \in \mathcal{Q}}$\;
\For{$iter = 1$ \KwTo $N_{max}$}{
  \tcc{环境重置}
  从 $\mathcal{D}$ 随机选取视频 $v$，随机读取16帧1080p YUV\;
  随机裁剪至 $540 \times 960$ 得到状态 $s = (Y, Cb, Cr)$\;
  \tcc{Actor前向: 生成动作}
  $a = (Y_a, Cb_a, Cr_a) \leftarrow \pi_\theta(s)$ \tcp*{在GPU 0上}
  \tcc{环境交互: 编码-解码-评估}
  \For{$q \in \mathcal{Q}$}{
    将 $a$ 写入YUV文件，通过 \texttt{hevc\_nvenc} 以QP=$q$编码\;
    解码重建帧，计算 $V_{cur}(q)$ (LPIPS) 和 $R_{cur}(q)$ (码率)\;
    $r(q) \leftarrow \alpha \cdot \Delta V(q) + \beta \cdot \Delta R(q)$\;
  }
  计算平均奖励: $R_{avg} \leftarrow \text{mean}(\{r(q)\}_{q \in \mathcal{Q}})$\;
  \tcc{Critic更新 (在GPU 1上)}
  $\mathcal{L}_{Critic} \leftarrow \text{MSE}(Q_\phi(s, a), R_{avg})$\;
  反向传播更新 $\phi$，同步参数到 $Q_{\phi'}$\;
  \tcc{Actor更新 (在GPU 0上)}
  $\mathcal{L}_{Actor} \leftarrow -Q_{\phi'}(s, \pi_\theta(s)) + w_{mse} \cdot \mathcal{L}_{mse} + w_{hf} \cdot \mathcal{L}_{hf}$\;
  反向传播更新 $\theta$，梯度范数裁剪至1.0\;
}
\end{algorithm}



\section{本章小结}

本章详细阐述了基于Actor-Critic架构的视频前处理优化系统的设计与实现。首先介绍了系统的总体架构和状态-动作空间设计，提出了基于Random Crop的高频保持训练策略。随后设计了基于相对率失真增益的多QP复合奖励函数，以及包含非边缘高频抑制的频域感知损失函数。在网络架构方面，详述了RAPNet(Actor)和ValueNet(Critic)的结构设计。最后给出了基于FFmpeg的NVENC编码环境搭建方案以及完整的多GPU训练算法。
