\chapter{绪论}

\section{研究背景与意义}

随着5G通信与流媒体技术的蓬勃发展，视频数据已成为全球互联网流量的主体，占比超过80\%。在实时视频通话、云游戏、远程办公与AR/VR等新兴场景中，用户不仅要求超低时延，还要求在有限带宽下获得高质量的视觉体验。然而，传统视频编码标准在面对这一需求时正面临严峻挑战：

\begin{itemize}
  \item H.264/AVC凭借其极高的兼容性虽然商用最为广泛，但在面对高清(1080P及以上)视频时，其压缩效率已显疲态，难以在低带宽下维持画质；
  \item H.265/HEVC虽然在同等画质下能节省约50\%的码率，但其碎片化的专利池与复杂的授权政策严重阻碍了其全面普及\cite{ref10-sullivan2012hevc}；
  \item H.266/VVC虽然率失真性能强大\cite{ref1-bross2021vvc}，但其编码计算复杂度相比H.265激增了数倍至数十倍，极高的编码时延完全无法满足端侧设备对实时交互的严苛要求。
\end{itemize}

与此同时，端到端深度学习编码方案虽然性能卓越，但受限于巨大的算力开销和功耗，难以在边缘设备上部署\cite{ref8-lu2019dvc}。此外，现有深度学习编码工具多针对传统编码框架的局部模块进行优化，缺乏对整体编码过程的感知，通常需要多阶段迭代训练以获得性能提升\cite{ref16-ding2021advances}。

面对这一瓶颈，传统的画质增强算法多依赖手工设计的滤波器，缺乏对图像内容的自适应能力；而学术界主流的深度学习增强模型（如基于Transformer的架构\cite{ref22-liang2022vrt,ref23-liang2022rvrt}）往往计算复杂度过高，且多以客观指标(PSNR)为优化目标，无法真实感知硬件编码器的压缩特性与主观视觉偏好。这也导致了高算力模型无法落地、低算力模型效果不佳的困境。

本研究正是在此背景下，旨在打破前处理与编码器之间的隔阂，引入一套轻量级的AI协处理方案——基于强化学习的智能前处理技术。该方案将硬件编码器视为环境，利用强化学习自适应调整增强策略，在极低的算力开销下解决硬件编码器在低码率下的感知质量瓶颈，从而在不牺牲硬件编码核心效率的前提下，显著提升用户的视觉体验。

\section{国内外研究现状}

过去三十余年，主流视频编码技术路线始终围绕变换、预测、环路滤波等规则驱动的模块化工具展开精细化设计与协同优化，并依托MPEG、AVS、AOM等标准化组织构建起成熟的生态体系\cite{ref1-bross2021vvc}。尽管H.266/VVC等新一代标准的压缩效率持续提升，但在工业界大规模商用场景中，受限于极高的计算复杂度、编码时延以及复杂的专利布局，H.264/AVC与H.265/HEVC仍占据着绝对主导地位。

近十年来，随着深度神经网络的快速发展，视频编码领域迎来了新的变革\cite{ref16-ding2021advances}。当前研究已逐渐分化为两条路线：一条是全AI端到端架构，通过深度网络完全替代传统流程\cite{ref8-lu2019dvc,ref6-li2021deep}，虽然在多个公开数据集上展现出优于H.265/HEVC的压缩效率\cite{ref10-sullivan2012hevc}，但其庞大的算力开销使其难以在边缘设备上部署；另一条是围绕固定硬件编码器进行前后处理协同的AI增强架构\cite{ref9-shen2011downsampling,ref11-vanam2023spie,ref12-vanam2023dcc}，在针对超分辨率\cite{ref2-chan2021basicvsr}、滤波去噪\cite{ref7-lin2019improved}、变换\cite{ref3-chen2018rl}、帧内帧间预测\cite{ref20-chen2023fastmfqe}等环节进行模块化替换或辅助增强。后者因其部署灵活、兼容H.26x标准的优势，成为当前工业界与学术界的研究热点。

\section{研究内容与主要工作}

本文围绕"硬件编码器 + 轻量前处理 + AI后处理"的视频编码协处理方案展开研究，主要工作包括：

\begin{enumerate}
  \item \textbf{课题研究与方案设计}：调研分析H.265硬件编码(NVENC)相较于软件编码的优劣势，特别是其在低功耗、高效率方面的特点以及可能存在的率失真性能损失问题。研究"硬件编码 + 轻量前处理 + AI后处理"的视频编码落地路径，设计一套能够兼顾低功耗和率失真性能的混合编码框架；
  \item \textbf{系统实现与模型构建}：搭建实验系统，集成NVENC硬件编码器，实现基于强化学习的RAPNet\cite{ref27-zhao2025rapnet}前处理算法，AI算法的模型参数量控制在1M以内；
  \item \textbf{实验验证与性能评估}：使用1080p分辨率、YUV420格式（NV12转换）的视频序列\cite{ref28-mercat2020uvg}，在800Kbps、400Kbps、200Kbps等码率点上进行量化验证，对比BD-Rate节省百分比、主观视觉效果、计算复杂度等指标。
\end{enumerate}

\section{论文结构安排}

本文共分为五章，各章内容安排如下：

第一章为绪论，介绍研究背景、研究意义、国内外研究现状及论文结构安排。

第二章介绍国内外研究现状与理论基础，涵盖视频编码标准演进、前后处理技术分析、强化学习基础以及本文所采用的关键技术。

第三章详细阐述系统设计与实现，包括基于Actor-Critic架构的视频前处理优化系统的整体设计、状态空间与动作空间的定义、复合奖励函数设计及网络损失函数建模。

第四章进行实验与结果分析，在多个码率点上对比"纯硬件编码"与"集成前后处理的硬件编码"方案，从BD-Rate、主观视觉效果、计算复杂度等多个维度进行评估。

第五章对全文进行总结，并对未来工作进行展望。
