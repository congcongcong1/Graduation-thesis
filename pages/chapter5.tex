\chapter{总结与展望}

\section{工作总结}

本文针对低码率场景下硬件编码器感知质量瓶颈问题，提出了一种基于强化学习的智能视频编码协处理方案。主要工作总结如下：

\begin{enumerate}
  \item 设计并实现了一套"硬件编码器 + 轻量AI前处理 + AI后处理"的混合编码框架，将不可导的闭源硬件编码器(NVENC)纳入优化回路，实现了前处理模型对编码器特性的感知与预补偿；

  \item 引入了基于Actor-Critic架构的RAPNet前处理网络，采用残差学习策略将动作空间约束为对原始帧的微调修正，并设计了基于相对率失真增益的复合奖励函数，在"质量与比特"之间实现了有效博弈；

  \item 提出了包含加权MSE损失、非边缘高频抑制损失和全变分平滑损失的频域感知复合损失策略，有效抑制了增强过程中的高频伪影，提升了生成图像的主观自然度；

  \item 在5个HEVC标准测试序列上进行了全面验证，取得了平均$-9.48\%$的BD-LPIPS增益，其中ParkScene和BasketballDrive序列分别达到$-13.45\%$和$-12.84\%$。模型参数量仅139K，单帧推理时间5.4ms，前处理开销仅占端到端时延的约$12\%$，验证了方案在实时编码场景中的工程可行性。
\end{enumerate}

\section{未来工作展望}

尽管本文的工作取得了一定的成果，但仍存在以下可以改进和继续研究的方向：

\begin{enumerate}
  \item \textbf{多分辨率自适应}：当前系统仅针对1080p分辨率进行了优化，未来可以探索分辨率自适应的前处理策略，使模型能够自动适配从720p到4K的不同分辨率输入；

  \item \textbf{端到端联合优化}：当前方案中前处理、编码和后处理模块相对独立，未来可以探索端到端的联合训练方案，进一步提升整体系统的率失真性能；

  \item \textbf{更多编码标准支持}：将研究扩展到H.266/VVC硬件编码器以及AV1编码器，验证方案的通用性；

  \item \textbf{实际部署与工程优化}：将模型部署到实际的视频通话或流媒体系统中，并进行模型量化、剪枝等工程优化以满足严格的实时性要求。
\end{enumerate}
